# 阶段 C 验收报告

## C1：可靠答案评估

- 固定样本：10 道题，每题 4 条 rollout，共 40 条。
- 人工逐条标注了候选文本明确表达的最终答案；无明确答案时标为 `null`。
- 自动抽取与人工标注一致：40/40，准确率 100%，高于 95% 门槛。
- 失败被拆成：推理错误 5 条、截断且无最终答案 12 条、正确 23 条；没有把“解析失败”误报成“推理错误”。
- 局限：抽取规则是在这 40 条样本上迭代形成的，因此 100% 是当前样本内验收结果，不等同于未知数据上的泛化准确率。后续正式实验应增加独立留出集。

## C2：真正的逐步 DORA

- 固定总预算为 4，完成 3 轮“生成一步 → PRM 打分 → BGE 多样性 → 重新分配”。
- 三轮整数分配依次为：`[1, 2, 0, 1]`、`[1, 1, 1, 1]`、`[2, 0, 1, 1]`。
- 第 0、2 轮为非均匀分配，满足至少两轮动态改变资源的要求。
- 验证脚本确认：分配总和始终为 4；被分配多个 rollout 的父路径被真实复制；每个子路径完整继承父文本，并在其后继续生成新文本。
- 最终答案质量仍较弱：4 条最终路径中 2 条有可抽取答案但均错误，另 2 条在 768 token 上限处截断。C2 验收的是搜索机制真实运行，不代表当前 1.5B Policy 已获得高任务准确率。

## C3：4-bit PRM 与混合 BF16 对照

- 对同一批 40 条冻结候选分别打分，只改变 PRM 加载精度。
- BF16 使用 CPU/GPU 混合放置，因此 8 GiB 显卡可以本地运行，无需为该对照租卡。
- Pearson：0.9958。
- Spearman：0.9883，超过 0.9 门槛。
- 组内两两排序一致率：95%。
- 严格 Top-1 一致率：100%，超过 90% 门槛。
- 相同 BGE 多样性和相同分配公式下，整数资源分配完全一致率：100%，超过 80% 门槛。

结论：阶段 C 的三个工程验收目标全部完成。当前样本支持在后续本地实验中使用 4-bit PRM 进行 DORA 分配；正式论文级结论仍需扩大问题数、使用独立留出集，并报告任务准确率与计算成本。
