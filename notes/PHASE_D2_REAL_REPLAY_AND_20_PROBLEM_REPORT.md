# 阶段 D2：真实轨迹重放与 20 题端到端报告

## 1. 研究目标

D2 回答两个递进问题：

1. D1 在合成数据上发现的整数分配差异，是否会在真实 PRM 分数和 BGE 相似度上出现？
2. 若三种分配方法各自生成后续搜索路径，这些差异是否会改变方向覆盖率和最终正确率？

本阶段使用本地 Qwen2.5-1.5B-Instruct Policy、4-bit Qwen2.5-Math-PRM-7B 和 BGE-M3，在 RTX 4070 Laptop 8 GB 上完成，不使用租赁 GPU。

## 2. 三种方法

| 方法 | 单轮预算 | 说明 |
|---|---|---|
| 官方独立取整 | 不一定守恒，随后补齐 | 对每个连续配额独立 `np.round`，再复现官方代码的重复、截断补齐 |
| 最大余数 | 严格守恒 | 向下取整后，把余数分给小数部分最大的候选 |
| 跨轮累计缺额 | 严格守恒 | 累计连续目标与实际分配之差，优先偿还历史缺额 |

官方补齐不是中性的：当独立取整只产生 3 个 rollout 时，官方实现会重复已展开的候选列表并截断到 4，因此靠前候选更可能获得补位。

## 3. 真实轨迹重放

重放使用 Phase C2 已保存的一道题、三轮真实 PRM 分数和 BGE 余弦矩阵。所有方法面对完全相同的候选和连续权重。

- 官方独立取整在 3 轮中有 2 轮只分配出 3 个 rollout，而不是预算 4；
- 第 0 轮官方补齐后为 `[2,1,0,1]`，最大余数为 `[1,2,0,1]`；
- 三种方法的比较行中有 4/9 与最大余数不同。

因此，整数化差异确实出现在真实模型信号上，不是 D1 合成分布的人造现象。但重放不能产生反事实后续候选，所以不能单独回答正确率问题。

## 4. 20 题端到端设计

| 项目 | 设置 |
|---|---|
| 数据 | MATH-500 固定 20 题 |
| 每题预算 | 4 条路径 |
| 分配轮次 | 3 |
| 每轮最大新增 token | 96 |
| 最终最大新增 token | 768 |
| Policy | Qwen2.5-1.5B-Instruct FP16 |
| PRM | Qwen2.5-Math-PRM-7B 4-bit NF4 |
| Embedding | BGE-M3 FP16 |
| 随机种子 | 20260829 |

每种方法独立运行完整轨迹。第 0 轮三组使用相同 Policy 候选和种子；最大余数与累计缺额第 0 轮完全相同，因此它们第 1 轮仍面对完全相同的候选和真实权重。

准确率报告三种口径：

- `pass@4`：四条候选中至少一条正确；
- 多数答案正确率：对可靠解析出的归一化答案投票；
- 候选级正确率：所有最终候选中正确答案的比例。

方向性报告三种互补口径：

- 非零分配候选数；
- 在余弦阈值 0.95 下的 complete-link 贪心方向簇数；
- 连续相似度有效方向数 `1/(p^T S p)`。

## 5. 端到端结果

| 方法 | pass@4 | 多数答案 | 候选正确率 | 截断率 | 候选覆盖 | 方向簇覆盖 | 有效方向数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 官方独立取整+补齐 | 15/20 | 13/20 | 52.50% | 21.25% | 3.233 | 1.717 | 1.0496 |
| 最大余数 | 16/20 | 13/20 | 51.25% | 23.75% | 3.367 | 1.917 | 1.0521 |
| 跨轮累计缺额 | 16/20 | 13/20 | 52.50% | 22.50% | 3.383 | 1.917 | 1.0522 |

官方方法的 60 个逐题分配决策中，13 个（21.7%）在补齐前违反预算 4。

## 6. 配对证据

### 官方方法与最大余数

- 第 0 轮共享真实候选上，4/20 题的整数分配不同；
- 其中 3 题由官方覆盖 3 个候选变为最大余数覆盖 4 个候选；
- 平均候选覆盖增加 0.133，配对 bootstrap 95% CI `[0.033, 0.233]`；
- 平均方向簇覆盖增加 0.200，95% CI `[0.067, 0.350]`；
- 有效方向数只增加 0.0025，95% CI `[-0.0010, 0.0060]`。

硬阈值方向簇显示覆盖改善，但连续有效方向数的区间跨 0。因此“方向覆盖提高”的结论对指标定义敏感，不能描述为全面或大幅的语义多样性提升。

### 最大余数与跨轮累计

- 第 0 轮 80/80 个权重和分配完全一致；
- 第 1 轮真实权重仍逐项一致，仅加入累计缺额后有 5/20 题改变分配；
- 最终 `pass@4`、多数答案正确率和方向簇覆盖完全相同；
- 候选覆盖只增加 0.017，95% CI `[-0.050, 0.083]`。

跨轮累计在真实信号上确实改变了分配，但当前 3 轮、20 题实验没有观察到它优于最大余数的任务收益。

### 正确率不确定性

官方到最大余数的 `pass@4` 增加 1 题。这一题正好在第 0 轮从官方 `[2,1,1,0]` 变为最大余数 `[1,1,1,1]`，与保留额外方向的机制一致。然而只有一个不一致题，McNemar 精确检验 `p=1.0`；多数答案正确率三组均为 13/20。因此当前证据不能证明最终正确率提升。

## 7. 可靠性与局限

1. 20 题是探索性小样本，不是论文规模复现，也没有统计功效支持 5 个百分点的准确率结论。
2. 最终候选自动解析成功 65–67/80；截断率仍为 21.25%–23.75%，长度预算是明显混杂因素。
3. 答案解析器曾在先前 40 条候选上达到 40/40 人工标签一致，但 D2 新候选未逐条人工复核。
4. 方向簇依赖 0.95 阈值和贪心 complete-link 定义；连续有效方向指标没有显示明确改善。
5. 跨轮累计债务按确定性的 beam slot 对齐。真实搜索中候选会复制、淘汰和换位，slot 不是稳定语义身份；因此该实现是可复现基线，不是最终理论方案。
6. 三种方法使用相同种子，但路径分叉后 prompt 不同，后续随机采样自然不再是逐 token 的同一反事实。
7. 当前结论只针对 1.5B Policy、预算 4、三轮搜索，不能外推到论文的较大模型和 64–256 rollout 设置。

## 8. D2 结论

D2 支持以下结论：

1. 官方独立取整的预算不守恒在真实 PRM+BGE 信号中频繁出现；
2. 官方补齐、最大余数和跨轮累计会在真实候选上产生不同整数分配；
3. 最大余数提高了非零候选覆盖，并在当前硬阈值方向指标上提高方向簇覆盖；
4. 跨轮累计会进一步改变真实分配，但没有显示出相对最大余数的最终收益；
5. 三种方法的多数答案正确率完全相同，当前不能声称整数化改进提高最终准确率。

最准确的阶段性表述是：

> 小预算整数化是一个真实、可测量的搜索实现问题；修正预算守恒能够改变路径覆盖，但在 20 题探索实验中尚未证明能提高最终答案正确率。
